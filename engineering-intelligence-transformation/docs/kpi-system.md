# KPI System

## Executive KPIs
- Onboarding time: down.
- MTTR: down.
- Repeat incidents: down.
- PR review time: down.
- Regression rate: down.
- Developer search time: down.
- AI cost per engineer: controlled.
- Retrieval answer usefulness: up.

## Platform KPIs
- P50/P95 answer latency.
- Token cost per request.
- Citation coverage.
- Retrieval precision sample score.
- Cache hit ratio.
- RBAC denied retrieval count.
- Prompt injection detection count.

## Agent KPIs
PR Guardian: findings accepted, false positive rate, security issues caught pre-merge.
Incident Agent: time to probable cause, recommendations used, repeat incidents reduced.
Remediation Agent: executed remediations, success rate, rollback/override count.
