# Operating Model

## AI Engineering Council
Members: VP Engineering sponsor, Platform lead, Security/CISO delegate, SRE lead, Architecture representative, FinOps/CFO delegate and Compliance/Legal when needed.

## Monthly Agenda
1. Adoption and usefulness metrics.
2. Cost by team/repo/agent.
3. Security findings and policy exceptions.
4. False positives and false negatives.
5. New data sources to index.
6. New runbooks proposed for automation.
7. Incident and remediation review.

## Agent Release Maturity
1. Observe only.
2. Recommend only.
3. Recommend and open PR/ticket.
4. Execute in non-prod.
5. Execute safe production action with approval.
6. Execute allow-listed safe production action automatically.
